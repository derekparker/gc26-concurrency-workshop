# new in Go 1.26 — goroutine counts by scheduler state /sched/goroutines/runnable:goroutines ready to execute, but not executing /sched/goroutines/running:goroutines executing (<= /sched/gomaxprocs) /sched/goroutines/waiting:goroutines waiting on I/O or a sync primitive /sched/goroutines/not-in-go:goroutines in a syscall or cgo call /sched/goroutines-created:goroutines total created since start /sched/threads/total:threads live runtime-owned threads # and, already there since Go 1.20: /sched/latencies:seconds time spent runnable before running

A rising runnable count and a fattening /sched/latencies histogram are exercise 1’s bug — visible without capturing a single trace. The counts are approximate and are not guaranteed to sum to /sched/goroutines:goroutines.
